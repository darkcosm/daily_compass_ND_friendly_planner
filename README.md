# Daily Compass

A free, private daily planner from [Her Own Terms](https://herownterms.me).

Open `index.html` in a current browser, or host this folder as a static site. There is no account, no server, and no analytics. Notes stay in this browser. Export a JSON file if you want a copy you can keep or move.

The page is a low pressure place for one day: mood and energy, three things, a brain dump, and a note that stays put. Blank lines are fine. Nothing is counted.

Fonts are included in `fonts/` so the page does not call a font service. They are under the SIL Open Font License. See [fonts/OFL.txt](fonts/OFL.txt).
